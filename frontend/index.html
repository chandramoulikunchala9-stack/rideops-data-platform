540 cells, zero differences

Postgres SQL and Spark compute the same daily revenue by city from the same 100,000 bookings. Every one of the 540 date and city cells matches: ₹13,095,490.51 in both.

Six data feeds into one lakehouse

The rider app, driver app, payments gateway, app telemetry and cloud billing each land in bronze Delta tables exactly once. Gold rebuilds only the dates that changed; Postgres serves it through 45 named SQL queries.

Questions about RideOps

Python PostgreSQL Apache Spark Databricks AWS Terraform FastAPI React GitHub Actions Docker

Is any of this real data?

No. A fixed seed generates every customer, driver and booking, with defects planted so the checks have work to do.

Are the RideOps cloud costs real?

No. They are simulated rows in the AWS cost report format, labelled simulated on every screen.

Where does RideOps run today?

In Docker on one laptop. The Terraform and the Databricks bundle validate but are not applied yet.

What went wrong while building RideOps?

Four incidents, each with a postmortem. One check reported 4 rejected bookings when there were 813.
